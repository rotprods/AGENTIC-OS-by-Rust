# GRAPH-REFACTOR-V2 — Implementation Program

## Program North Star
A zero-context authorized successor reconstructs the same bounded project truth, ownership, evidence, graph neighborhood and next safe action from durable authority in <=5 minutes, without prior chat.

## Checkpoints

### CP0 — Live Truth Reconciled
Entry: repository reachable. Exit: main/F1/Survival topology, open PRs, current heads and authority boundaries recorded; parallel Survival branch defect resolved by convergence plan.
DoD: no stale PR/branch treated as current authority.

### CP1 — Ontology + Lexicon Frozen
Exit: typed node/edge ontology, COS projection map and authority lexicon published; unused dimensions marked NOT_APPLICABLE.
DoD: no ambiguous `verified/complete/active` semantics.

### CP2 — Historical Regression + Gap Classification
Exit: V1→V2 delta and ranked gap/risk matrix exist; every P0/P1 has owner/test/evidence/phase.

### CP3 — V2 Architecture Frozen
Exit: source-of-truth matrix, component boundaries, security/recovery/overengineering policies accepted.

### CP4 — Survival Contracts Executable
Tasks: checkpoint/project-state/session/handoff/context schemas; reference reducer; freshness validation; canonical hashing.
Tests: schema accept/reject, deterministic hash, replay/idempotency, stale head/event-horizon rejection.
DoD: same accepted history yields same state/checkpoint hash.

### CP5 — Cross-Language Contract Parity
Tasks: Rust/TS/Python implementations and golden fixtures for continuity contracts.
DoD: bytes/hash/schema accept-reject parity 100%.

### CP6 — Event/State Kernel
Tasks: append-only reference event store, expected revision, idempotency, parent causality, watermark, snapshot/replay.
DoD: duplicate same event idempotent; same identity different payload fails closed; stale revision rejected.

### CP7 — Agent/Session/Claim Kernel
Tasks: session lifecycle, semantic/file scopes, claims, barriers; leases/fencing only if runtime need is demonstrated.
DoD: semantic collision detected even without file overlap; stale owner cannot self-promote.

### CP8 — COS Projection
Tasks: event/state→typed COS bundle; deterministic projection hash; one-way adapter.
DoD: delete graph and rebuild from authority → same canonical hash/query answers.

### CP9 — ContextPack / Memory
Tasks: bounded query compiler, source-head/event-watermark/projection seal, invalidation engine, TTL classes.
DoD: upstream change makes old pack unusable for writes.

### CP10 — Assurance Architecture
Tasks: unit/contract/schema/property/mutation/integration/security/replay/recovery/death-drill suites; escaped-bug corpus; claim-scoped evidence metadata.
DoD: every critical invariant maps to authoritative test evidence.

### CP11 — Recovery + Agent Death Drill
Tasks: destroy chat/local checkout/cache/graph; reconstruct state; synthetic zero-context successor evaluation.
DoD: same bounded state/blockers/ownership/next action within <=5 minutes and <=1 ContextPack.

### CP12 — Security Gauntlet
Attack: prompt injection, provider poisoning, secret/PII leakage, path/URL/shell injection, stale writer, duplicate spend, replay corruption, evidence substitution, authority self-promotion.
DoD: P0/P1 = 0; residual risks explicit.

### CP13 — Operator / Developer UX
Tasks: `agentic-os status/context/claim/checkpoint/handoff/recover/doctor`; README_FIRST; runbooks.
DoD: zero-context operator can inspect without editing authority manually.

### CP14 — Migration / Project Bootstrap
Tasks: project template and `agentic-os init .`; non-destructive adoption path for existing repos; historical import as superseded evidence.
DoD: bootstrap does not create competing source of truth.

### CP15 — Durable Backend Trigger Gate
Default: DEFER. Promote only if measured need exists for concurrent multi-process/multi-host transactional authority.
Candidate implementation may be SQLite local/reference first; Postgres only on measured trigger.

### CP16 — Whole-System Gauntlet
Simulate crashes, duplicate/reordered events, stale ContextPack, simultaneous agents, deleted graph, conflicting docs/state, provider timeout-after-acceptance, main advancing after CI.
DoD: no silent overwrite or false authority.

### CP17 — Production Authority
Requires all applicable prior checkpoints exact-head green, promotion preflight, rollback, P0/P1=0 and explicit authority decision.
